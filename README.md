
# php скрипт для OpenWrt для конвертаци Happ подписок в построчный список серверов

Данный скрипт полностью маскируется под клиент Happ и получает доступные сервера в формате JSON, сервера на выходе возвращаются в формате ссылок (vless://, trojan://, hysteria2://, ss://)## Поддерживаемые протоколы

Список протоколов и их транспорта, которые скрипт распознаёт и конвертирует

- **VLESS** (TLS, Reality): TCP, WS, xHTTP, gRpc
- **TROJAN** (TLS): TCP
- **HYSTERIA2** (TLS)
- **SHADOWSOCKS**: TCP

## Возможности

- Автоматическая генерация и передача **X-Hwid** под конкретное устройство
- Поддержка клиентов, не умеющих распознавать формат подписок JSON (например V2RayA)
- Локальная работа на устройстве, не требует внешних сервисов или инструментов
## Установка

### Установка необходимых пакетов

`Для OpenWrt 24.10 и ниже`
```bash
  opkg update
  opkg install php8 php8-cgi php8-mod-curl php8-mod-mbstring php8-mod-filter
```
`Для OpenWrt 25.12`
```bash
  apk update
  apk add php8 php8-cgi php8-mod-curl php8-mod-mbstring php8-mod-filter
```

### Увеличение памяти, выделяемой роутером для php
```bash
  nano /etc/php.ini
```
В строке `memory_limit = 8M` поменять на 16M (либо больше, для больших подписок)

### Установка самого скрипта
```bash
  wget https://uncaught1.github.io/happ-to-vless/happ_to_vless.php -O /www/happ_to_vless.php
```

### Перезапуск веб-сервера роутера
```bash
  /etc/init.d/uhttpd restart
```

### Проверка работы скрипта
Откройте сайт `http://(IP адрес роутера, без квадратных скобок)/happ_to_vless.php`

Должно получится (пример): `http://192.168.1.1/happ_to_vless.php`

Если открывается небольшая текстовая инструкция - php работает и скрипт установлен

### Добавление подписки через скрипт в VPN клиент OpenWrt
Скрипт поддерживает кодирование списка в base64, для выбора режима используется выражение прямо в ссылке `base64=true` или `base64=false`

Пример данного параметра для популярных VPN-клиентов:
- `base64=true`: Forkop, NetShift, Trafira
- `base64=false`: V2RayA

Добавьте подписку в ваш VPN-клиент:

`http://(IP адрес роутера, без квадратных скобок)/happ_to_vless.php?base64=true|false&url=(ссылка на подписку от провайдера впн как есть, без скобок)`

Должно получится (пример):

`http://192.168.1.1/happ_to_vless.php?base64=true&url=https://вашвпн.сайт/подписка`
